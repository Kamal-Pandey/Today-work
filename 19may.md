# 🧑‍💼 HRMS - Booking, Timesheet & Task Management System

A modern **HRMS module** built in React for managing:
- Resource Booking (Admin + Self Booking)
- Daily Timesheet Tracking
- Task Type Standardization
- Project Allocation


---

## 🚀 Key Features

### 📅 Booking System
- Admin & Self booking support
- Project-based resource allocation
- Start & End date booking

---

### ⏱ Daily Timesheet
- Task-wise daily logging
- Project-based work tracking
- Dynamic task entry system
- Status tracking (Completed / In Progress)
- Calendar-based date selection
- Add multiple task rows dynamically

---
