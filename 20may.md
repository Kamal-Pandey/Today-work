# 📊 Project Utilization Report (Frontend Module)

This is a React-based frontend module added to an existing project to display Project Utilization Reports.

It helps in tracking:
- Allocated Hours
- Booked Hours
- Utilized Hours

---

## 🚀 Implementation

- Added a new Project Utilization Report page
- Built reusable components:
  - ReportFilters (filters UI)
  - ReportTable (table with pagination & sorting)
  - ReportChart (bar chart visualization)
- Integrated API using fetch
